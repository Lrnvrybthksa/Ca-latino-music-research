# Latino Music Industry in California (Late 2026)

An interactive, single-page report on California's Latino music industry: market size, regions, trending genres, artists (Spanish, English and bilingual), festivals, radio, trends, outlook, and a growth-strategies tab with 12-month plans for artists, music channels and content brands.

Open `index.html` in a browser. To publish it as a website, turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Figures come from the sources listed in the page (RIAA, Luminate, Billboard, Pollstar and others), as of November 2026.
